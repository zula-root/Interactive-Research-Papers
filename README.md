**Live site:** https://zula-root.github.io/Interactive-Research-Papers/

## Run locally

The pages load scripts, so serve the folder instead of opening files directly:

```
python3 -m http.server
```

Then open http://localhost:8000.

## Accuracy

These are summaries, not substitutes for the papers. If you spot an error, please open an issue.
